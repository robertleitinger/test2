# Mega-Prompt-Bibliothek

Fertige Anweisungen zum **Kopieren und Einfügen** in deinen KI-Assistenten. Jede Datei folgt demselben Aufbau:

1. **Ziel** — was du damit erreichst.
2. **Mega-Prompt** — der Text zum Kopieren (Platzhalter in `[ECKIGEN KLAMMERN]` ersetzen).
3. **Erwartetes Ergebnis** — woran du erkennst, dass es geklappt hat.
4. **Häufige Fehler** — und wie du sie vermeidest.

## So nutzt du sie (3 Wege)
- **Einfügen:** Kopieren → in den Chat → Platzhalter ersetzen → abschicken.
- **Als Skill speichern:** z. B. in Claude Code als wiederverwendbaren Befehl ablegen.
- **In Ordner ablegen:** z. B. bei Cowork in einen Vorlagen-Ordner legen.

Alle Prompts sind **tool-neutral** — sie funktionieren mit Claude Code, Claude Cowork/Desktop, Codex u. a.
